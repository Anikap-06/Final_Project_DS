# Introduction
This project investigates whether K-Means clustering improves customer classification performance.

# How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Open notebook:
   notebooks/analysis.ipynb

3. Run all cells

# Dataset
Customer segmentation dataset from Kaggle:   https://www.kaggle.com/datasets/vetrirah/customer

# Models Used
- Logistic Regression
- Random Forest
- K-Means Clustering
- PCA (visualization)
